# AI Travel Planner Agent

A professional AI-powered travel planning web application built with React + Vite and integrated with IBM watsonx Orchestrate.

## Features

✈️ **AI-Powered Travel Planning**
- Destination recommendations
- Personalized itineraries
- Hotel recommendations
- Transportation guidance
- Budget planning
- Weather forecasts
- Local attractions
- Food recommendations

🎨 **Premium UI/UX**
- Modern, responsive design
- Glassmorphism effects
- Smooth animations
- Travel-inspired theme
- Mobile-first approach

🤖 **IBM watsonx Orchestrate Integration**
- Real-time AI chat interface
- Production deployment connection
- Official Web Chat Loader

## Quick Start

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
